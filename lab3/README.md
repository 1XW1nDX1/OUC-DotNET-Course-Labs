# Lab3 温度校准值搜寻器

- 开发工具：Visual Studio Community 2026
- 目标框架：.NET Framework 10.0

## 运行说明

进入项目目录后，运行`.\bin\Release\net10.0-windows\Temperature Calibration Value Searcher.exe`，或使用Visual Studio自带的调试功能启动

## 任务核心说明

### 1 - 创建一轮校准

定义了一个`StartNewCircle()`函数，用来在点击“开始新一轮”后在目标范围内生成一个随机目标值，赋值给全局变量`targetTemperature`并设置当前有效区间

随机生成的目标值除了测试函数外没有修改入口，从而保持目标值不变

在Form1实例化的时候开始设置一些初始值，并在FormLoad的时候调用一次`StartNewCircle()`自动开始新一轮

### 2 - 校验并更新区间

输入校验：在提交（`Commit()`）函数开头使用两个if-else语句，先判断是否提交，再判断输入值是否为空，然后再判断是否不为数字，再判断数字是否不合法，每一步判断为是的时候就返回，中断函数，不进入后续修改状态的语句

### 3 - 历史记录与循环

定义了一个Commits类，借助它的属性来存储一个合法提交

在输入校验逻辑后增加一个if-else语句，判断用户的合法输入并给出提示消息，并将该次提交加入`records`列表，完成时进入`Evaluate()`函数，进行打分评价后使用`foreach`遍历`records`并使用Commit类里的函数得到每个实例对应的字符串并Add到Listbox的Items里

## 拓展任务

### 1

根据已有标准评价表现（简单难度下，分级为1-3-5；一般难度下，分级为1-4-6；困难难度下，分级为1-5-9），非法输入不计入，对应次数记录逻辑在检验输入之后

### 2

利用枚举定义难度，利用RadioButton选择难度，在`StartNewCircle()`开头添加难度检测，根据不同的难度把初始区间两个端点确定下来，再利用这个时候确定的端点来开始新一轮
